# zarr-spectral-schema (Python binding)

Python binding for the CCAT/CHAI L0–L1 Zarr store contract. Constants and the
validator are *derived* from the spec (`spec/schema.yaml`), shipped here as
package data — there is no hand-typed duplicate of the contract.

```python
import zarr_spectral_schema as zss

zss.DATA_5D  # "data_5d"   — spec-derived constant
zss.L0_SCHEMA_VERSION  # "3"
problems = zss.validate("path/to/store.zarr")  # [] == conformant
problems = zss.validate("s3://bucket/store.zarr")  # needs the `s3` extra
```

An `s3://` store takes its endpoint and credentials from the standard AWS
environment (`AWS_ENDPOINT_URL`, `AWS_ACCESS_KEY_ID`, …). The validator reads
only `zarr.json` objects, never a chunk.

The synced `spec/` directory under the package is generated by `make sync` at the
repo root; do not hand-edit it. See the repo README and `docs/adr/0007-…` for the
design.
